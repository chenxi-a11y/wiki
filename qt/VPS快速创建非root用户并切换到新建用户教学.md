有些时候我们使用vps或者服务器的时候，有些文件执行需要使用非root用户来操作才可以，那么怎么创建普通用户那，本篇文章带你学习在vps上面创建普通用户，并且直接切换到新建的用户！

### 创建非 root 用户：

1. 以 root 用户登录：
   - 使用 root 用户或具有 sudo 权限的用户登录到你的 linux vps ssh窗口系统。
2. 创建用户：
   - 使用 `adduser` 命令创建新用户。这里我们以 `username` 当做用户名，你可以把 `username` 替换为你想要设置的非root用户名，也就是普通用户名。然后在你vps上执行代码即可！

```undefined
sudo adduser username
```

系统会提示你设置密码和提供一些额外需要的信息。

### 切换到新用户：

1. 切换用户：
   - 使用 `su` 命令切换到新创建的用户。将 `username` 替换为你创建的用户名。

```undefined
su - username
```

如果你希望保留当前用户环境那就直接用下面命令切换：

```undefined
su username
```

**验证切换：**

- 确保你已经成功切换到新用户。你可以执行 `whoami` 命令来检查当前登录的用户名。

```undefined
whoami
```

如果用户名显示为你创建的新用户，说明切换成功。

### 注意事项：

- **sudo 权限：** 在默认情况下，Linux 系统不会将用户直接添加到 sudo 组。如果需要将用户添加到 sudo 组以获取管理员权限，请执行以下命令：

```undefined
sudo usermod -aG sudo username
```

- **安全性：** 设置强密码，并确保只将必要的权限授予新用户。

这些步骤是在 linux vps系统上创建和切换到非 root 用户的基本过程。在进行敏感操作之前，请确保你了解新用户的权限和系统安全性。
